# Student Management System

A Class 12 CBSE-style **Student Management System** built with:
- **Python classes**
- **Tkinter GUI**
- **SQLite database**

## Run

```bash
python student_management_system.py
```

## Features

- Add student
- Update student
- Delete student
- Search student by roll number
- View all students

Data is stored in `students.db` in the project directory.
